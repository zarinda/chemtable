# ChemTable — дизайн

Эстетика модернистского научного плаката: горчичный фон, холодная бумага, чистый чёрный, категории различаются цветом и фактурой. Продуктовые решения — в [docs/SPEC.md](docs/SPEC.md).

## Темы

«Горчичная» (по умолчанию) и «ночной плакат» (тёмная). Выбор по `prefers-color-scheme` плюс переключатель. Палитра в `src/app.css`; для OG-картинок и PDF она продублирована в `src/lib/server/palette.ts` — менять в обоих местах.

### Категории = цвет + фактура

Каждая категория отличается не только цветом, но и фактурой заливки (сплошная, точки, штриховка, полутон). Так таблица читается без цветового зрения и в ч/б печати, и сразу видна связь с референсами.

### Типографика

- **Oswald** (кириллица): символы элементов, названия, заголовки. Bebas Neue заглавный по устройству и превратил бы «Fe» в «FE», поэтому символы набираем Oswald.
- **Bebas Neue:** только крупные цифры (атомный номер на плакате, значения на тепловой карте).
- **Golos Text:** текст, подписи, значения свойств, `font-variant-numeric: tabular-nums`.
- Шкала: 12 / 14 / 16 / 21 / 28 / 37 / 50 / 120+ (дисплейные цифры на плакате).

### Телефон (≤ 760 px)

Не уменьшенный десктоп: на первом экране то, за чем пришли. Макеты — [docs/mockups/](docs/mockups/) (`mobile-home.jpg`, `mobile-home-dark.jpg`, генератор `mobile.mjs`); пользователь одобрил их 12.10.

**Страница элемента — сделано 12.10.** Сверху клетка элемента (номер малиновым Bebas, символ Oswald, тень 5 px) и название; размер названия по длине (> 10 знаков — 30 px, > 7 — 36 px, иначе 44 px), все 944 названия в одну строку при 360 px. Под ними категория и четыре ключевых числа 2×2, затем свойства «подпись над значением», затем схема оболочек (без крупного номера и полосы — номер уже в клетке), «Соседние элементы». Кнопки — закреплённая панель внизу: «← Mn · Закрыть · Co →».

**Главная — «карта + лупа», сделано 12.10** (портретный телефон, `(max-width: 760px) and (orientation: portrait)`). Отличия от макета: заголовок — полное название страницы (h1 для SEO), легенда с полными названиями категорий (пользователь выбрал: точнее, без новых переводов), номер в клетке карточки цветом текста категории (малиновый не читается на малиновой/бирюзовой заливке), актиноиды в тёмной теме горчичные — уже отличаются от переходных. View Transitions не делали.
- Вся таблица во всю ширину (шаг ≈ 20 px при 390, ≈ 18 px при 360): цвет категории + символ Oswald ~10,5 px, без номеров и названий. Заголовок «Таблица Менделеева» над таблицей, не в пустоте между блоками. Номера групп мелко сверху.
- Тап по клетке не открывает элемент, а выбирает его; ведение пальцем меняет выбор на лету (pointer events, `touch-action: none` только на таблице). Над пальцем — «лупа» (бумажная клетка ~66×72 с номером и символом, тень 4 px).
- Под таблицей карточка выбранного элемента: клетка 104 px, название Oswald, английское название, категория · состояние, атомная масса Bebas; крупные круглые ← → (44 px) и «Открыть ›». Это и есть альтернатива мелким клеткам по размеру цели (WCAG 2.5.8).
- Чипы режимов листаются вбок; легенда в две колонки, короткие названия категорий. В режиме свойства миниатюра становится тепловой картой.
- Фактуры в клетках 20 px перерисовать мельче (точки 3,5–6 px), иначе шум. В тёмной теме актиноиды сливаются с переходными металлами — нужен заметно другой оттенок.
- Горизонтальная ориентация телефона — обычная таблица с названиями.
- По желанию: «Открыть» раскрывает карточку в страницу через View Transitions.

## Принципы

1. **Смелость в одном месте:** раскрытие клетки в плакат. Всё остальное строгое и тихое.
2. **Одна анимация без участия пользователя:** сборка таблицы по атомным номерам 1→118 при загрузке. При `prefers-reduced-motion` её нет.
3. **Все остальные движения отвечают на действия:** смена фильтра перекрашивает клетки волной по номерам, раскрытие и закрытие плаката.
4. **Структура несёт смысл:** точки и линии в пустотах таблицы декоративны только по виду. На деле это электронные оболочки (точки = электроны выбранного элемента).
5. **Зерно и полутон:** общий SVG-шум поверх фона, как печать на плакате.
6. **Качество по умолчанию:** фокус с клавиатуры (стрелки двигаются по таблице), контраст AA, reduced motion. На тепловой карте светлый текст чисто белый: бумажный в середине шкалы не дотягивает до 4,5:1. `aria-label` клетки начинается с видимого текста (WCAG 2.5.3).

## Сверка с типовыми решениями (что изменено)

- Кремовый фон заменён на холодный серый `#E6E3DA`, ближе к 4-му референсу.
- Чёрный чистый `#000`, без «тонированного почти-чёрного».
- Моноширинный шрифт для данных не используем, вместо него Golos Text с tabular-nums.
- Без ALL CAPS-подписей над блоками. Заглавные буквы есть только там, где они в природе шрифта (цифры Bebas).
- Категории различаются не только цветом, но и фактурой. Это прямо вытекает из референсов и одновременно решает доступность.
