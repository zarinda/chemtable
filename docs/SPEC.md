# ChemTable — спецификация

Интерактивная таблица Менделеева в эстетике модернистского научного плаката.

## Продукт

- **Аудитория:** школьники и студенты, международная.
- **Языки:** 8 — en (корень сайта), ru, fr, de, it, es, zh (упрощённый), pt (бразильский). Каждый язык — отдельные адреса с префиксом: /ru/iron. Переводы, кроме en и ru, сделаны без носителя и помечены `reviewed: false` в src/lib/i18n/locales/.
- **Главный экран:** таблица на весь вьюпорт, других секций нет. Внизу короткий футер с источниками.
- **Клик по элементу:** клетка разрастается в полноэкранный плакат элемента (FLIP-анимация), закрытие возвращает её на место.
- **Данные в плакате:**
  - базовые: номер, символ, название, атомная масса, группа, период, блок, агрегатное состояние, электронная конфигурация;
  - физико-химические: t° плавления и кипения, плотность, электроотрицательность (Полинг), первая энергия ионизации, степени окисления, атомный радиус.
- **Фильтры:**
  - по категории: 10 категорий, легенда сама работает как фильтр;
  - тепловые карты: атомная масса, электроотрицательность, атомный радиус, плотность, t° плавления, энергия ионизации.
- **Ссылки на элементы:** у каждого элемента своя статическая страница по английскому названию IUPAC (`/iron`, `/ru/iron`). Символы не подходят: `/ru`, `/fr`, `/es`, `/pt` — это и коды языков, и элементы. Открытие из таблицы меняет адрес без перезагрузки, «Назад» закрывает плакат.
- **Пояснения:** у каждого свойства на плакате кнопка «?» с объяснением для школьников; под шкалой тепловой карты — описание закономерности.
- **Радиус:** PubChem отдаёт ван-дер-ваальсов радиус, поэтому свойство так и называется, с пояснением, чем он отличается от радиуса из учебника.
- **Мобильная версия:** в альбомной ориентации вся таблица, в портретной горизонтальный скролл с закреплённой колонкой периодов.
- **Темы:** «горчичная» (по умолчанию) и «ночной плакат» (тёмная). Выбор по `prefers-color-scheme` плюс переключатель.

## Данные

- Источник: PubChem Periodic Table (NIH), атомные массы сверяем с IUPAC CIAAW (стандартные атомные массы, актуальная редакция).
- Скрипт `scripts/fetch-elements.ts` один раз выгружает данные и собирает `src/lib/data/elements.json`. В каждой записи хранится ссылка на источник.
- Названия элементов на всех языках, Wikidata ID и ссылки на Википедию — из Wikidata (тот же скрипт).
- `npm run fonts` — подмножество Noto Sans SC для китайского текста (в том числе редкие иероглифы новых элементов).
- `npm run og` — OG-картинки в `static/og/{lang}/{slug}.png`; рендерит только недостающие, `-- --force` пересоздаёт все (~15 минут). Палитра продублирована в `src/lib/server/palette.ts` (зеркало `app.css`, общая для OG и PDF): после смены цвета удалить затронутые картинки и перезапустить.
- `npm run pdf` — таблица для печати в `static/print/{lang}/`: A4 и US Letter, альбомные, цветная и экономичная ч/б (категории различаются фактурой), 32 векторных PDF (~17 МБ, ~1 мин). Нужен установленный Chrome, Edge или Chromium (`CHROME_PATH`). В клетке: номер, электроотрицательность, символ, название, масса, электроны по слоям; ключ и легенда — в пустой области над переходными металлами. Домен напечатан на листе: после смены `PUBLIC_SITE_URL` перегенерировать.
- `npm run favicon` — иконка сайта (клетка «Ct») в `static/`: `favicon.svg`, `favicon.ico` 48 px (для Google), `apple-touch-icon.png`.
- Лицензия данных: CC BY 4.0 (`DATA_LICENSE` в `src/lib/seo.ts`): Dataset JSON-LD, `elements.json`, `llms.txt`, ссылка `rel="license"` на главной.

## SEO

- Адрес сайта: https://chemtable.org. Он же значение по умолчанию `PUBLIC_SITE_URL` (см. `.env.example`), так что сборке в CI переменная не нужна. После смены домена: `npm run pdf` (домен напечатан на листе) и `npm run build`; OG-картинки домена не содержат.
- Каждая страница: title, description, canonical, hreflang на 8 языков + x-default, Open Graph, Twitter, JSON-LD (WebSite, Dataset на главной; WebPage, ChemicalSubstance, BreadcrumbList на элементах).
- Страница элемента содержит серверную статью: сводка, таблица свойств, соседние элементы, ссылки на Википедию, PubChem, Wikidata.
- Клетки таблицы — ссылки `<a href>`, плакат открывается поверх без перезагрузки.
- Для краулеров: `/robots.txt` (явно разрешены AI-краулеры), `/sitemap.xml` с hreflang, `/llms.txt`, `/llms-full.txt`, `/data/elements.json`, `/data/elements.csv`.

## Стек

- SvelteKit (adapter-static) + TypeScript.
- Bits UI: dialog, toggle group, tooltip, без собственных стилей.
- Анимации: Svelte transitions + `flip` и FLIP вручную для раскрытия клетки.

### Типографика

- **Oswald** (кириллица): символы элементов, названия, заголовки. Bebas Neue заглавный по устройству и превратил бы «Fe» в «FE», поэтому символы набираем Oswald.
- **Bebas Neue:** только крупные цифры (атомный номер на плакате, значения на тепловой карте).
- **Golos Text:** текст, подписи, значения свойств, `font-variant-numeric: tabular-nums`.
- Шкала: 12 / 14 / 16 / 21 / 28 / 37 / 50 / 120+ (дисплейные цифры на плакате).

## Принципы

1. **Смелость в одном месте:** раскрытие клетки в плакат. Всё остальное строгое и тихое.
2. **Одна анимация без участия пользователя:** сборка таблицы по атомным номерам 1→118 при загрузке. При `prefers-reduced-motion` её нет.
3. **Все остальные движения отвечают на действия:** смена фильтра перекрашивает клетки волной по номерам, раскрытие и закрытие плаката.
4. **Структура несёт смысл:** точки и линии в пустотах таблицы декоративны только по виду. На деле это электронные оболочки (точки = электроны выбранного элемента).
5. **Зерно и полутон:** общий SVG-шум поверх фона, как печать на плакате.
6. **Качество по умолчанию:** фокус с клавиатуры (стрелки двигаются по таблице), контраст AA, reduced motion. На тепловой карте светлый текст чисто белый: бумажный в середине шкалы не дотягивает до 4,5:1. `aria-label` клетки начинается с видимого текста (WCAG 2.5.3).

## Сверка с типовыми решениями (что изменено)

- Кремовый фон заменён на холодный серый `#E6E3DA`, ближе к 4-му референсу.
- Чёрный чистый `#000`, без «тонированного почти-чёрного».
- Моноширинный шрифт для данных не используем, вместо него Golos Text с tabular-nums.
- Без ALL CAPS-подписей над блоками. Заглавные буквы есть только там, где они в природе шрифта (цифры Bebas).
- Категории различаются не только цветом, но и фактурой. Это прямо вытекает из референсов и одновременно решает доступность.
