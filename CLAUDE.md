## Данные — главное правило

Ученики должны получать проверенные данные. **Оценку не выдаём за измерение**: предсказанное помечается «предсказано», неизмеренное не показывается («нет данных»).

- `src/lib/data/elements.json` руками не править: он собирается `npm run data` из PubChem, CIAAW, NIST, Wikidata и [scripts/corrections.ts](scripts/corrections.ts).
- Любая ручная правка — только в `scripts/corrections.ts`, с причиной (`why`) и ссылкой на источник.
- Новое свойство или новый источник сверять поле за полем со вторым независимым источником. Как делался аудит 12.10: скачать wheel пакета `mendeleev` (`pip download mendeleev --no-deps`), открыть `mendeleev/elements.db` через sqlite3 (CRC Handbook, NIST, NUBASE2020) и сравнить с `elements.json`; расхождения разбирать вручную по третьему источнику (Википедия с первоисточниками, Wikidata). Сайт RSC закрыт Cloudflare-проверкой — curl не проходит.
- Известные допустимые расхождения (не ошибки) перечислены в SPEC → «Данные».
- Wikidata SPARQL: тяжёлые `P279*` по широким классам дают 504, параллельные запросы сбоят — делать последовательно и узко. `P1086` (атомный номер) — decimal: в `VALUES` фильтровать по QID элемента, а не по числу.
- Неполные данные Wikidata (у кюрия только Сиборг) правятся в самой Wikidata, затем `npm run data`.

```sh
npm run dev       # dev-сервер; только здесь виден макет рекламы (?ad=off, ?ad=300, ?adpos=top)
```

## Особенности кода

- SvelteKit 3 + Svelte 5 + TypeScript, adapter-static, Bits UI.
- Импорты через `#lib/...` с расширением `.ts`. Окружение: `src/env.ts` и `'$app/env'` (`dev`, `browser`), **не** `'$app/environment'`.
- Плакат — `Dialog.Portal disabled`: портал Bits UI монтируется только в браузере, и страница элемента без JS показывала бы таблицу. Не возвращать портал.
- Подписи в плакате переносятся `hyphens: auto` по `<html lang>`. Headless Chrome на Windows не знает словарей ru/de и рвёт слово без дефиса — на телефонах перенос с дефисом.
- В плакате есть глобальный стиль `.name` — не использовать этот класс внутри плаката.
- Стиль кода: табы, одинарные кавычки, без завершающих запятых, ширина ~100. **Конфига prettier нет** — не запускать `npx prettier` с настройками по умолчанию: он перепишет файлы двойными кавычками и пробелами.
- Ключ свойства `atomicRadius` теперь означает ковалентный радиус (Cordero 2008); ключ не переименован, чтобы не ломать URL и код.
- Реклама: `#lib/ads.ts` (`showAds`, `adOnTop`, `ADS_LIVE` — переключает раздел «Реклама» в политике конфиденциальности); `AdPreview.svelte` импортируется динамически внутри `{#if dev && showAds()}` и в проде не загружается.
- Главная на телефоне (портрет ≤ 760 px, `MAP_QUERY` в `state.svelte.ts`, тот же запрос в CSS компонентов): таблица-карта, касание выбирает элемент (`app.picked`, геттер `pickedZ`), а не открывает; Enter открывает. Указатель захватывает `.grid` (`setPointerCapture`), элемент под пальцем — `elementFromPoint`; лупа — в `Table.svelte`, карточка — `PickCard.svelte`. Заголовок страницы — отдельная первая строка сетки таблицы (на десктопе пустая), поэтому `grid-row` клеток = `row + 2`. `--cell` задан через `cqw` — внутри клетки (она сама size-контейнер) `var(--cell)` пересчитывается от клетки и даёт 0: размеры внутри клетки задавать в `cqw`. Порядок блоков на телефоне — через `order` и `display: contents` у шапки `Controls`. Мелкие фактуры — `--texture-sm` в `app.css`.
- Плакат на телефоне (≤ 760 px): клетка `.tile` в шапке, `.nav` — `position: fixed` внизу; у `.poster` переопределено `contain: none !important` (иначе fixed-панель прокручивается). Фокус при открытии — на самом `.poster` (`{@attach focusOnMount}`, автофокус Bits UI отключён), чтобы не было рамки на «←»; стрелки/Tab/Escape проверять после каждой правки плаката.
- Скриншоты для проверки: `puppeteer-core` из node_modules + системный Chrome `C:/Program Files/Google/Chrome/Application/chrome.exe`. На странице элемента ждать `[role="dialog"] dl` — плакат открывается после загрузки JS. Playwright MCP не подключался.
- Страница 404: маршрут `[[lang]]/404` пререндерится в `build/404.html`, `build/ru/404.html`…; Cloudflare (`not_found_handling: "404-page"`) отдаёт ближайшую по пути со статусом 404. Поэтому `paths.relative: false` в `vite.config.ts` (иначе `../_app` ломается на `/ru/a/b`), а язык в `load` берётся из `url`, не из `params` (в браузере маршрут не совпадает). Подсказки элементов по адресу — `#lib/guess.ts`. Проверять локально: `npx wrangler dev` (перед `npm run build` остановить — держит `build/`).
- Lighthouse TBT на этой машине шумит ±40% — сравнивать медианы 3+ прогонов.
- Страница «Распечатать» (ветка `print-page`): маршрут `[[lang]]/print` (`+page.server.ts` читает размеры PDF из `static/` при пререндере), компонент `PrintPage.svelte` со своими meta и JSON-LD, адрес — `printPagePath` в `seo.ts` (`printPath` в `#lib/print.ts` — это сам PDF). Превью `…-{640,1600}.webp` рядом с PDF, делает `scripts/pdf.ts`. Меню языков и кнопка темы вынесены в `Prefs.svelte` (проп `pathFor`); куда открывается меню — переменные `--menu-left`/`--menu-right` (на телефоне в `Controls` — вправо).
- Страницы свойств: маршрут `[[lang]]/[property=property]` рендерит тот же `Home` с `page.data.property`; адреса — `PROPERTY_SLUG` в `elements.ts` (`atomicRadius` → `covalent-radius`), `propertyPath` в `seo.ts`. `app.mode` — геттер: на странице свойства всегда её свойство, кнопки в `Controls` там — ссылки (`nav.modes`), «Категории» ведёт на главную. Список — `PropertyValues.svelte` (под `{#key property}`, чтобы сортировка сбрасывалась), остаётся под плакатом, открытым из него. Тексты — `propertyPage` в локалях; объяснение берётся из `explain`, тренд показывает `Legend` под шкалой.
- Предпросмотр останавливать фильтром `CommandLine -match 'preview'` (PowerShell, `Stop-Process`): фильтр `'vite.js preview'` не совпадает (в строке кавычка), старый сервер остаётся жить и отдаёт прошлую сборку без CSS.
