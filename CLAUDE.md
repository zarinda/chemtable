## Данные — главное правило

Ученики должны получать проверенные данные. **Оценку не выдаём за измерение**: предсказанное помечается «предсказано», неизмеренное не показывается («нет данных»).

- `src/lib/data/elements.json` руками не править: он собирается `npm run data` из PubChem, CIAAW, NIST, Wikidata и [scripts/corrections.ts](scripts/corrections.ts).
- Любая ручная правка — только в `scripts/corrections.ts`, с причиной (`why`) и ссылкой на источник.
- Новое свойство или новый источник сверять поле за полем со вторым независимым источником. Как делался аудит 12.10: скачать wheel пакета `mendeleev` (`pip download mendeleev --no-deps`), открыть `mendeleev/elements.db` через sqlite3 (CRC Handbook, NIST, NUBASE2020) и сравнить с `elements.json`; расхождения разбирать вручную по третьему источнику (Википедия с первоисточниками, Wikidata). Сайт RSC закрыт Cloudflare-проверкой — curl не проходит.
- Известные допустимые расхождения (не ошибки) перечислены в SPEC → «Данные».
- Wikidata SPARQL: тяжёлые `P279*` по широким классам дают 504, параллельные запросы сбоят — делать последовательно и узко. `P1086` (атомный номер) — decimal: в `VALUES` фильтровать по QID элемента, а не по числу.
- Неполные данные Wikidata (у кюрия только Сиборг) правятся в самой Wikidata, затем `npm run data`.

## Команды

```sh
npm run dev       # dev-сервер; только здесь виден макет рекламы (?ad=off, ?ad=300, ?adpos=top)
npm run check     # svelte-check, должен быть 0 ошибок
npm run build     # статика в build/
npm run preview   # после каждой пересборки перезапускать — иначе отдаёт 404 на новые ассеты
npm run data      # пересобрать elements.json (сеть: PubChem, CIAAW, NIST, Wikidata)
npm run pdf       # 32 PDF для печати (~1 мин), после смены данных, палитры или домена
npm run og        # OG-картинки (только недостающие; -- --force все, ~15 мин)
```

## Особенности кода

- SvelteKit 3 + Svelte 5 + TypeScript, adapter-static, Bits UI.
- Импорты через `#lib/...` с расширением `.ts`. Окружение: `src/env.ts` и `'$app/env'` (`dev`, `browser`), **не** `'$app/environment'`.
- В плакате есть глобальный стиль `.name` — не использовать этот класс внутри плаката.
- Стиль кода: табы, одинарные кавычки, без завершающих запятых, ширина ~100. **Конфига prettier нет** — не запускать `npx prettier` с настройками по умолчанию: он перепишет файлы двойными кавычками и пробелами.
- Ключ свойства `atomicRadius` теперь означает ковалентный радиус (Cordero 2008); ключ не переименован, чтобы не ломать URL и код.
- Реклама: `#lib/ads.ts` (`showAds`, `adOnTop`); `AdPreview.svelte` импортируется динамически внутри `{#if dev && showAds()}` и в проде не загружается.
- Скриншоты для проверки: `puppeteer-core` из node_modules + системный Chrome `C:/Program Files/Google/Chrome/Application/chrome.exe`. На странице элемента ждать `[role="dialog"] dl` — плакат открывается после загрузки JS. Playwright MCP не подключался.
- Lighthouse TBT на этой машине шумит ±40% — сравнивать медианы 3+ прогонов.
